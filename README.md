# Gimbit
ENERGY PARKOUR — YOUR ASSETS

The game now uses the supplied:
- sky background
- two character skins (cropped from your sprite sheet)
- energy artwork
- logo
- platform artwork

Firebase:
1. Enable Anonymous Authentication.
2. Enable Realtime Database.
3. Put your Web App config into index.html.
4. Apply firebase-rules.json as your RTDB rules.
5. Host the folder on Cloudflare Pages, Netlify, GitHub Pages, etc.

Questions are in the QUESTIONS array in index.html.
